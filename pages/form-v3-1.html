제품기획안 양식 v3.1 · 조사에서 1T를 도출한 뒤 전략을 정한다

이 양식의 목적은 누가 무엇을 원해서, 어떤 대안 대신 우리 제품을 선택하고, 어떤 설명을 들었을 때 그 가치를 이해하는지를 제작자가 재질문 없이 이해하게 만드는 것입니다. 목차는 읽는 순서입니다. 조사하거나 생각하는 순서를 강제하지 않습니다.

제품 공통 정보는 한 번만 정리하고, 선택 이유가 다른 1T는 필요한 만큼 나눕니다. 한 사람이 여러 상황에 걸칠 수 있습니다. 나이만 다르거나 같은 문장을 반복하는 집단은 억지로 나누지 않습니다. 타깃을 많이 적는 것이 완성도는 아닙니다.

구분 이 문서에서의 뜻
1T 고객조사에서 확인한 구체적인 선택 상황을 공유하는 고객. 원하는 변화, 이미 해보거나 피한 대안, 현재 선택을 막는 이유와 선택 조건이 드러나야 함. 갱년기·친밀감·피로 같은 넓은 범주는 조사 영역
결핍·욕구 지금 아쉬운 상태와 바라는 변화. 성분명·제품명으로 대신하지 않음
타깃의 CV 그 고객이 해결책을 고를 때 끝까지 중요하게 여기는 핵심 가치
우리 R의 CV 그 욕구에 대해 우리 제품이 제공하려는 핵심 가치. 제품이 실제 구현하는 근거와 함께 제시
포지셔닝 고객의 선택지 안에서 우리 제품을 어떤 이유로 기억하고 선택하게 할 것인가
물길 고객이 고민을 드러내는 곳에서 설명·비교·구매까지 이어지는 실제 이동 경로
고객스크립트 고객의 문제 인식과 선택이 어떻게 달라질지 정리한 설득 흐름. 고객의 실제 발언이나 광고 대본과 구분

모든 중요한 문장에는 관찰 / 기존 기획 의도 / 해석 / 새 제안 / 검증할 가설 / 미확인 중 상태와 근거를 붙입니다. 참고자료는 관점과 용어를 이해하는 데 사용합니다. 평가용 정답지는 별도로 관리합니다.

00. 출발점과 이번 결정 범위

작성할 것 기록할 내용
이번 작업 기존 제품 문서화 / 새로운 아이디어 기획 / 타사 기획 복원 중 선택
주어진 것 아이디어·시장·기존 제품·사업 조건·참고자료·정답지를 구분
이번에 결정할 것 고객·가치·포지션·제품 방향·판매검증·제작 범위
현재 제약 실제 확인된 예산·일정·공급·제품·경로와 아직 가정인 것
문서 상태 조사 범위, 작성일, 버전, 지금 제작 가능한 부분과 판매 확정에 부족한 부분

완료 기준: 입력으로 알았던 내용과 이번에 새롭게 도출한 선택이 구분됩니다. 기존 제품의 기획을 사후 복원한 경우 당시의 실제 사고과정으로 단정하지 않습니다.

01. 한 장 요약 — 누구에게 어떤 가치로 들어가는가

유효한 1T와 첫 실행 우선순위를 나눠 적습니다. 공통 CV가 성립하지 않으면 제품 하나에 억지로 하나를 붙이지 않습니다.

1T·해결을 찾는 순간 원하는 결과·타깃 CV 핵심 경쟁 대안 우리 R의 CV·제품 근거 물길·첫 실행 확신과 남은 확인
실제 자료로 식별 고객 관점의 변화 같은 욕구를 해결하는 선택지 제공 가치와 구현 근거 구체적인 경로와 제작물 채택·시험·보류 이유

완료 기준: 각 행을 따라 읽으면 고객→대안→가치→제품→마케팅이 연결됩니다. 요약에 본문에 없는 새 약속을 넣지 않습니다.

02. 고객 조사와 1T 도출

전략으로 넘어가기 전의 조건: 먼저 사례별 고객의 상황과 선택을 조사합니다. 넓은 시장을 나눈 뒤 예상 욕구를 붙이는 것만으로 1T 도출을 완료하지 않습니다. 여러 사람의 발언을 합쳐 한 사람의 경험으로 만들지 않습니다.

사례 단위로 추가 확인할 것 기록 기준
해결이 필요한 구체적 상황 본인이 무엇을 바꾸고 싶은지, 왜 지금 해결을 찾는지
기존 생각과 해결 방식 무엇을 원인·답이라고 믿고, 무엇을 실제로 해봤는지. 처음 탐색이면 미시도로 기록
시도·포기·거절·전환 무엇이 부족했으며 지금 어디로 옮기거나 무엇 때문에 멈추는지
받아들일 조건 어떤 결과·부담·근거·가격이라면 선택이 달라질지. 원문 진술과 추론 구분
1T 후보와 다른 후보의 차이 대안·CV·제품 조건·설명이 달라질 정도의 실제 차이인지

유사한 선택 구조의 반복과 반대 사례를 대조해 후보를 정리합니다. 아직 모르는 선택 조건이 핵심이면 조사 중으로 남깁니다. 형용사를 많이 붙이거나 모든 후보에 실패 경험을 강제로 넣는 방식으로 구체화하지 않습니다.

1T마다 정리할 고객 카드

항목 담을 내용
계기와 상황 최근 실제로 문제가 생겼거나 해결을 찾게 된 장면
바라는 변화 기능·생활·감정·관계상의 변화. 전부 하나의 상위 욕구로 환원하지 않음
사용자·구매자·영향자 서로 같은지, 다르면 각자가 원하는 것과 충돌하는 지점
실제 대응 이미 시도한 제품·서비스·습관·무대응, 지출·수고·중단·전환 이유
선택과 거절 기준 무엇이 갖춰져야 사고, 무엇이면 아무리 좋아 보여도 안 사는가
차이와 겹침 다른 1T와 공통인 부분, 다른 설명·대안을 요구하는 부분
근거와 반대 자료 원문 번호, 해석의 확신, 맞지 않는 사례, 미확보된 목소리

채널별 수집표

채널·찾는 질문 확보한 원문과 날짜 원문의 화자·상업 관계·열람 범위 실제 말·행동 해석·적용 1T 기획에 미친 변화
커뮤니티·쇼핑 후기·상담 질문·검색·영상 댓글 등에서 필요한 채널 선택 URL·수집일·본문/댓글 구분 광고·제휴·자사몰·불명, 전문/일부/제목만 구분 짧은 직접 인용과 행동 요약 고객 진술과 연구자의 추론 구분 CV·대안·제품·소재 중 바뀐 결정

제품명 검색만 하면 이미 제품을 아는 사람과 홍보글에 치우칩니다. 문제·상황·기존 대안·실패·비구매 검색을 함께 사용합니다. 같은 글의 본문과 댓글, 여러 채널의 재게시를 독립 고객으로 중복 집계하지 않습니다. 홍보 관계가 불명인 글은 자발적 목소리라고 확정하지 않습니다. 번역 리뷰는 국내 고객의 원어와 분리합니다.

완료 기준: 채널별로 조사한 결과와 공백이 보이고, 고객의 말에서 전략으로 넘어간 근거를 추적할 수 있습니다. 건수를 채우려고 관련 없는 글을 넣지 않습니다. 중요한 해석이 한 자료·오래된 글·판매자 후기만으로 성립하면 가설로 남깁니다.

03. 1T별 경쟁 지형과 경쟁사의 실제 운영

경쟁사 선정이 먼저입니다. 이번에 깊게 역설계할 주력 업체는 해당 1T에게 실제로 잘 파는 근거가 있어야 합니다. 브랜드/회사/개별 SKU, 실적 기간, 실제 실적/회사 발표/플랫폼 표시/추정을 나눠 적습니다. 유명하다는 이유나 같은 원료, 검색 노출·추천·후기 수만으로 선정하지 않습니다. 어떤 채널에서 잘하는지까지 확인해 우리가 배우려는 판매 방식과 연결합니다. 성과 미확보 사례는 주력 경쟁으로 통과시키지 않고 참고로 구분합니다.

주력 경쟁 후보 같은 1T에게 선택되는 근거 잘 파는 근거·대상·기간·출처 잘하는 채널·방식 이번 역설계에서 배울 것 채택·보류
업체·실제 상품 욕구·선택 상황의 연결 누적 브랜드 실적과 현재 SKU·채널 성과 구분 확인/미확인 구분 CV·프레임·물길 등 근거가 약하면 참고로 남김

최소 조사 깊이: 대표가 지정한 A03과 동형님 시장조사 수준을 적용합니다. 핵심 경쟁 대안의 실제 제품·SKU·상세 전체를 확인하고, 성분 목록뿐 아니라 CV·문제 정의·프레임 분리·근거 제시·반론 해소·가격/오퍼의 순서를 분석합니다. 브랜드 소개만 읽고 실제 상세 분석으로 처리하지 않습니다.

채널별로 실제 소재·날짜·화자·본문·댓글·제품명 공개·검색/링크·도착 상세를 연결합니다. 상품별 메시지가 어떤 고객의 기존 생각·욕구·거절 이유에 대응하는지도 대조합니다. 원문·화면·구매 조건을 확보하고 핵심 공백이 남으면 조사 완료로 판정하지 않습니다. 사례의 업체 수·자료 수를 모든 제품의 고정 할당량으로 복사하지 않습니다.

같은 욕구의 대안

1T 대안·실제 비교 또는 사용 근거 얻으려는 것 선택/중단 이유 우리 제품의 유불리·부적합 확인 수준
고객 카드와 연결 동종·다른 성분·서비스·습관·버티기·미구매까지 후보로 열기 욕구와 연결 고객 관찰과 예상 부담 구분 상대 대안을 깎아내리지 않고 판단 실제 대체/잠재 대안/미조사

관련 있어 보이는 모든 대안이 직접 경쟁은 아닙니다. 실제 비교·전환·예산 충돌이 확인된 대안은 더 깊게 조사하고, 연관성만 있는 것은 후보로 둡니다. 경쟁 범위는 성분에서 출발해 닫지 않고 고객의 선택 행동으로 좁힙니다.

경쟁사의 물길

업체·연결되는 1T 채널·날짜·원문 주목을 끄는 문제와 화자 본문·댓글의 설득 검색·링크·도착 페이지·가격 제안 확인한 반응과 한계 우리 계획에 적용할 것
고객 욕구 기준으로 선정 실제 열람 자료 브랜드·전문가·일반 사용자·불명 구분 본문과 추천 댓글 구분 어디로 가서 무엇을 하게 하는가 조회/댓글/효능 주장과 실제 성과 구분 단순 모방 대신 검증할 선택

완료 기준: 시장조사는 상품 목록을 넘어 어디서 어떤 말로 팔고 어디로 연결하는지까지 설명합니다. 못 본 댓글·도착지·현재 집행은 공백으로 남깁니다. 검색량·광고 수·후기 수를 매출이나 성공 원인으로 바꾸지 않습니다.

04. CV와 포지셔닝의 선택

진입 조건: 02의 구체적인 1T 후보와 선택 구조, 03의 실제 경쟁 설득을 같은 고객 기준으로 대조할 수 있어야 합니다. 왜 기존 방법으로 해결하지 못했고 어떤 가치가 있으면 선택이 달라질지 근거로 설명하지 못하면 주력 1T·CV·포지션은 미선정 상태입니다. ‘가설’ 표기만으로 이 조건을 충족한 것으로 처리하지 않습니다.

1T 고객이 원하는 결과 선택 기준 우리 R의 CV 가설 제품이 제공하는 근거 대안 대신 고를 이유·남는 약점 우선순위와 뒤집힐 조건
고객 카드 연결 도달하고 싶은 상태 체감·비용·부담·신뢰 등 그 결과에서 우리가 맡을 가치 사실·검증/미검증 구분 차이가 없으면 없다고 판단 주력/병행/보류와 이유

CV 확인 질문: 성분·제형·안내 문구를 지우고도 고객이 왜 돈을 내는지 남는가? 그 결과가 다른 대안보다 우리 제품에 맞는 이유가 있는가? 편의가 실제 핵심 구매 이유라면 CV가 될 수 있으나, 자료 부족을 메우려고 편의를 승격하지 않습니다.

고객이 바라는 결과, 제품 개발 목표, 현재 입증한 제공 능력, 밖에 내보낼 표현을 따로 적습니다. 원하는 결과를 조사하는 것과 그 결과를 상품이 보장한다고 광고하는 것은 다른 판단입니다.

완료 기준: 주력 선택이 분명하고, 다른 유효 1T가 사라지지 않습니다. 욕구가 있다는 이유만으로 제품 적합성을 확정하지 않습니다.

05. 제품 방향과 구현

가치·해결할 일 필요한 제품 특성·사용 경험 기존 제품의 실제 상태 또는 새 제품 목표 대안 대비 차이 검증 방법·미충족 시 결정
1T의 CV와 연결 성분·성능·제형·서비스·구성·이름·디자인 중 필요한 것 실제값/개발안 분리 고객이 중요시하는 차이 유지·개발·다른 타깃·중단

완료 기준: 보기 좋은 설명만으로 제품 차별성을 대신하지 않습니다. 기존 제품이 고객의 기대에 맞지 않으면 제품 개선이나 공략 제외도 결론이 될 수 있습니다.

06. 실제 조건과 판매검증 모델

제품 공통 사양·식품유형 등 해당 분류·가격·옵션·배송·재고·원가·수익성·주의사항의 정본과 미확인을 정리합니다. 판매 조건은 대표가 준 실제 조건과 새 제안을 구분합니다.

지금 검증할 모델 검증 전에 필요한 것 개발·제조 전에 확인할 것 병행할 수 있는 준비 결정권자·담당
베타 상세·소재·콘셉트·판매 형태 고객에게 약속 가능한 가치·정보·공급 조건 수요·가격·불만·제품 구현 가능성·수익성 설계·견적·시안 등 미배정이면 미배정으로 표시

완료 기준: 새로운 제조를 먼저 해야만 기획을 시험할 수 있는 구조를 강제하지 않습니다. 베타 검증에서도 실제 제공하지 못하는 성능·재고·후기·배송을 사실처럼 제시하지 않습니다.

07. 채널별 공략과 구매 동선

1T·인식 단계 채널을 택한 고객 근거 말투·형식·화자 첫 소재·검색어 도착 페이지·다음 행동 차별점·측정
이미 파악한 고객 상황 고객이 실제 고민/비교하는 곳 익명 후기 흉내 대신 실제 주체 제작 가능한 수준 상세의 어느 구간으로 가는지 무엇을 확인하고 경로를 바꿀지

완료 기준: 03의 운영 조사를 반복하지 않고, 우리 제품이 어디서 어떻게 실행할지 결정합니다. 모든 채널에 동일한 글을 복사하는 계획으로 끝내지 않습니다.

08. 설득과 고객스크립트

1T마다 현재 생각→전환할 관점→우리 제품을 고려할 이유→의심과 반론→확인 자료→선택 행동을 적습니다. 고객의 원문은 근거 번호로 붙이고, 기획자가 만든 문장은 창작으로 표시합니다.

완료 기준: 공감 다음에 성분 설명을 붙였다는 이유만으로 설득이 완성되지 않습니다. 제품을 고를 이유와 안 고를 이유를 모두 설명할 수 있어야 합니다.

09. 상세페이지 제작 명세

구간·대상 1T 이 구간이 답할 고객 질문 제목·본문 초안 이미지·표·제품 증거 연결한 VOC·제품 근거 다음 행동·현재 상태
공통 하단과 타깃별 도입 분리 가능 고객의 실제 의심 바로 시안에 넣을 수준 필요한 자료 지정 실제 발언과 새 카피 구분 사용 가능·근거 보완·보류

완료 기준: 제목 목록만 주지 않고 문구·장면·증거·연결을 줍니다. 미확인 값을 제작자가 임의로 채우지 않게 합니다.

10. 콘텐츠 소재 제작 명세

1T·채널·목적 제목·첫 문장 본문 흐름·완성 초안 이미지/영상 장면 도착·행동 근거·시험할 차이
채널 언어와 연결 어떤 욕구를 건드리는가 실제 고객 후기와 구분한 창작 제작에 필요한 지시 어느 상세로 보내는가 반응에서 무엇을 배울지

완료 기준: 해당 채널용 첫 실행물이 있습니다. 검증되지 않은 효과를 암시로 우회하거나 실제 구매자를 꾸며내지 않습니다.

11. 실행·판매검증·개발 결정

가장 틀리면 안 되는 가설 지금 할 시험 기록할 실제 행동 성공/보류/중단의 판단 다음 제품·마케팅 결정
욕구·대안·CV·가격·제품 적합 중 선택 인터뷰·비공개 시안·허용된 베타 판매 등 최근 선택·이해·오해·비구매·결제·반품 수치가 있으면 출처/가정 구분 예산과 실행 책임 포함

클릭과 좋아요는 관심의 신호입니다. 구매·사용 만족·반복구매·제품 효과는 각각 별도 확인합니다. 근거 없는 공통 전환율 기준이나 임의 표본 수를 모든 제품에 강제하지 않습니다.

12. 근거·결정·제작 전달표

근거 ID 원문·날짜·열람 범위 어떤 관찰인가 해석·반대 자료 연결한 결정과 제작물
원문 단위로 관리 본문/댓글/검색 발췌·상업 관계 제품 사실·고객 진술·판매자 주장 분리 미확인과 확신 1T→CV→제품→물길→상세/소재

마지막에 확정 / 새 제안 / 보류 / 담당에게 확인할 사실을 정리하고, 제작자에게 넘길 파일·필수 문구·자료가 없는 칸을 적습니다. 대표가 중간 추론을 모두 읽지 않아도 선택·근거·미확인·바뀔 조건으로 검토할 수 있게 합니다.

v3.1 검수 기준 · 조사 완료와 문서 완성도를 구분

통과시키지 않는 조건: 핵심 1T가 넓은 증상·욕구 분류에 머물러 있거나, 실제 대안 선택을 설명하지 못하거나, 주요 경쟁사의 상세·채널 설득이 확인되지 않았다면 기획안 완료로 통과시키지 않습니다. 문장·디자인·목차·출처 개수·소재 원고의 완성도로 이를 상쇄하지 않습니다. 이미 만든 상세·소재는 조사 가설을 알아보는 참고 시안으로만 취급합니다.

검수 영역 확인할 실패
고객 이해 문제 검색 없이 제품명 후기만 모았는가, 여러 욕구를 하나로 환원했는가
경쟁 이해 성분이나 상품군으로 경쟁을 닫았는가, 모든 후보를 직접 경쟁이라 부풀렸는가
가치·제품 속성·안내 편의로 CV를 대체했는가, 고객 욕구를 제품의 증명된 능력처럼 썼는가
채널과 제작 채널별 원문이 결정·소재에 반영됐는가, 시장조사에서 실제 실행으로 넘어갔는가
근거 정직성 광고·번역·중복·오래된 자료·미열람을 구분했는가, 반대 자료가 판단을 바꿨는가
문서 사용성 제작자가 추가 질문 없이 초안을 만들 수 있는가, 미확인을 임의로 채우게 두었는가

이 기준은 기존 첫 회차의 88/86점 산식을 바꾸지 않습니다. 양식 자체의 100점 근접 여부는 문서만 받은 제작자의 결과와 여러 제품 적용으로 별도 검증해야 합니다.

현재 루비맥스 적용 상태: v3의 A/B/C/D는 조사 영역으로 되돌렸으며 A 주력과 그 CV·포지션의 채택을 보류했습니다. 지정 기준 재점검 페이지에서 부족한 근거와 다음 조사 범위를 확인합니다. v3.1은 작성·판정 기준의 교정본이며, 루비맥스 조사를 이 수준으로 모두 수행했다는 결과물이 아닙니다.

공개 원문을 바탕으로 작성한 대표 전용 조사·양식 검토본입니다. 최종 제품기획·판매 성과·양식 점수를 확정한 문서가 아닙니다.
